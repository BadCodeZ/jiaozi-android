## 1. 视觉层级模型（L0–L3）

```
L0  页底     surface / background       暗 #0A0A0A · 亮 #F7F7F7
L1  卡片     surfaceContainer           暗 #242424 · 亮 #FFFFFF   （+卡片阴影 2dp）
L1b 卡内元素 surfaceContainerHigh        暗 #2C2C2C · 亮 #E8E8E8
L2  悬浮件   玻璃 / 浮空导航             暗 = 页底 + 白 10%       （+悬浮阴影 8dp）
L3  模态     全屏 Dialog / Sheet         scrim #52000000 + L2 底
```

**硬性**：L1 与 L0 的灰阶差在暗色下 **≥15 阶**（当前 **26 阶**，十七校由 18 阶提升）；L1b–L1 保持 8 阶（三档等距，不构成可辨的第二层级线）。
**阴影只有两级**：卡片 2dp（`CardTokens.Elevation`）/ 悬浮 8dp（`NavTokens.Elevation`）。不允许出现第三级。

## 2. 颜色落地规则

| # | 规则 | 禁区 |
|---|---|---|
| C-1 | 需要"品牌蓝"只认 `MaterialTheme.colorScheme.primary`；语义蓝只认 `AppColors.blue`。二者**恒等** | 不新增第二支蓝 |
| C-2 | 正文/图标前景用 `onSurface`；次级用 `onSurfaceVariant` | 不用 `primary` 充当常规文本/图标色 |
| C-3 | 需要"卡片底"只用 `surfaceContainer`（及 High/Highest） | 不写死 `#1A1A1A`/`#242424` |
| C-4 | 任何字面量先登记 `AppPalette` | 禁止在业务文件写 `Color(0xFF…)` |
| C-5 | 语义浅底（blueBg/greenBg/redBg/purpleBg/warningBg）只做**卡面/徽章底**，不做页面底 | 不用它做主背景 |
| C-6 | 深色下语义**前景**提亮、**容器**压深 | 不要同时提亮前景与容器（会失去对比） |

## 3. 玻璃材质落地规则

| # | 规则 |
|---|---|
| G-1 | 玻璃控件只有三档 spec：`NavSpec`（主胶囊）/ `IndicatorSpec`（选中底）/ `ButtonSpec`（= NavSpec）。**新控件一律复用，不新造 spec** |
| G-2 | 明暗**不分开调参**：`HighlightLightScale = 1.0`，两侧同一套窄带（1.5dp / 2.5dp / α.5） |
| G-3 | 受光带必须保持"边缘跃变"，有效衰减宽度 **≤3dp**（当前实测 2.9dp / 14px）。想"更明显"只能加峰值，不能加宽度 |
| G-4 | 深色玻璃**必须比页底亮**（`ALPHA_DARK = 0.10` → 内部 42 vs 页底 18）。任何让深色玻璃变暗的改动都是错的 |
| G-5 | 选中态靠**图标变 primary + 放大**识别；色块只允许 `ALPHA_DARK_SELECT = 0.015`（总 α 0.1135，内部 ≈45）。不许靠叠厚不透明度 |
| G-6 | 玻璃内 `lens` 的实际收益极小（`ContentBottomPad=92dp` 使背后恒为纯色），别把观感寄托在折射上 |
| G-7 | 形变走真实布局尺寸，禁止 `graphicsLayer{scaleX}`（会破坏 backdrop 采样） |

## 4. 图标与内容色（tint）

> 十六校定稿，此前三圆钮"颜色不对"的**唯一根因**就是默认 tint 用错了语义。

| 场景 | tint |
|---|---|
| 玻璃圆钮（设置 / 返回 / 关闭 / 任意 `GlassIconButton`）默认 | **`onSurface`** |
| 底部导航未选中 | `onSurface` |
| 底部导航选中 | `primary` + 图标放大 |
| 快捷入口四键（practice / mock / wrong / weak）图标 | `AppColors.blue` |
| 主动作按钮（FAB / 主 CTA） | `primary`，图标 `onPrimary` |

**自查命令**：`grep -rn "GlassIconButton(" ` 后确认没有显式 `tint = …primary`；`PracticeSetupSheet` 那处历史特例已删除。

## 5. 排版落地规则

生效档位（全工程实测，`fontSize = X.sp` 计数）：

| 档位 | 计数 | 使用 |
|---|---|---|
| 11 | 30 | 角标 / 徽章（`labelSmall`） |
| 13 | 84 | 辅助说明 / 正文小档（`bodySmall`、`labelMedium`） |
| 14 | 36 | 次级正文（工程主流值，已登记，不属于孤值） |
| 16 | 41 | 正文 / 按钮（`bodyLarge`、`titleSmall`、`labelLarge`） |
| 18 / 20 / 24 / 28 / 32 / 48 | 各 1–4 | 页标题族 / 大数字（倒计时、倒计时大字 48 为刻意） |

规则：
- **不再新增 12 / 15 / 17 / 10** 这类"档位之间"的字号——它们与邻近档位差 1sp，肉眼不可辨，却会让层级失去意义（十六校已全量归位，共 **73 处**）。
- 一切字号最终受 `JiaoziTheme` 的字体缩放护栏：系统 0.85–1.15、总倍率 ≤1.60。**新增定高容器前先算 1.6× 字号是否还放得下**。

## 6. 圆角与间距落地规则

生效圆角（实测）：`4dp` 微角 / `8dp` 芯片 / `9dp`（刻意：知识方徽章）/ `12dp` 卡内元素 / `16dp` 卡片内元素与卡片 / `20dp` 卡片默认 / `24dp` 大容器 / `26dp`·`28dp` 大幅面 / `999dp` 胶囊与圆钮。

规则：
- 卡片一律 **20dp**；卡内元素 12dp；芯片/小徽章 8dp；胶囊圆钮 999。
- **孤值（10/14/6/3/2dp）已全量归位**（十六校，约 **50 处**）；`9dp` 是"知识卡方徽章"的刻意值，**保留**。
- 间距/高度只有两个悬浮层级：内容底部留白固定引用 `NavTokens.ContentBottomPad = 92dp`，禁止散写 `bottom = 76dp` / `88dp`。

## 7. 无障碍

| 组合 | 对比度 | 结论 |
|---|---|---|
| `onSurface` #F2F2F2 on `surface` **#0A0A0A** | **17.7:1** | AAA（页底压深后由 16.7 升） |
| `#F2F2F2` on `surfaceContainer` #242424 | **13.9:1** | AAA |
| 暗态 `primary` #4C9DF8 on **#0A0A0A** | **7.06:1** | AA+（正文；由 6.68 升） |
| `#8F8F8F`（未采用） on #242424 | 4.6:1 | 仅可用作 disabled |
| onSurfaceVariant #B0B0B0 on **#0A0A0A** | **9.1:1** | AAA（由 8.6 升） |

> 十七校 C-1 页底压深 `#121212`→`#0A0A0A` 的**附带收益**：所有「前景 on 页底」组合对比度同步上升，
> 全站无一处因此跌破 AA。玻璃侧不受影响（α 决定叠加量，浮起量 +24 不变）。

正文/图标按 AA 4.5:1、大字号 3:1 卡线；任何新色必须现场算对比度再落 token。

## 9. 调平记录（十六校 · 本轮实际改动）

**改动**：字号孤值归位（73 处）、圆角孤值归位（约 50 处），两工程同源同步。

**编译**：正式仓 + 镜像工程均 `BUILD SUCCESSFUL`；警告数未超基线（4 条既有 deprecated）。

**真机实测（小米 13，1080×2400@440）**：

| 判据 | 结果 |
|---|---|
| 跨构建首页逐像素 diff | 非零 **0.596%**，均值 0.996 |
| 差异分布 | 全在 **y 43–900**（Hero 区 / 今日目标卡 / 任务卡文字）；**y > 2100 导航栏区 diff = 0** |
| 溢出/截断 | 无（首页、设置页真机截图逐页核验，卡片、分隔线、chip 均正常） |
| 关键色未漂移 | 齿轮 `#F2F2F2`、页底 `#121212`、卡片 `#363636` / `#242424` 与改前一致 |

**结论**：这是一次**纯一致性收编**——观感变化极小（文字 +1sp、圆角 ±2dp），但把设计系统从"12 种圆角 / 10 种字号"收敛到"7 档圆角 / 10 档字号且全部落在 token 上"。

## 10. 变更与验收流程（每次 UI 改动都走）

1. **先定口径**：改什么 → 对应哪条 token → 期望的可测量数字。
2. **编译**：`GRADLE_USER_HOME=D:/gh14 gradle --offline assembleDebug`，无 error、警告不超基线。
3. **装机**：`adb install -r`（路径必须 Windows 形式），`am start` **必须带 `force-stop`**（否则恢复上次页面，基线作废）。
4. **取基线**：同场景截图 → 与改前逐像素 diff。
   - 改材质：玻璃上方内容区 diff 必须 **0.0**；
   - 改字号/圆角：允许差异，但**不得溢出容器**、不得触及导航栏区。
5. **零回归**：另一主题（浅/深）同场景 diff 检查。
6. **交付**：归档 APK + 对比图 + 本文件 §8/§9 同步更新。
